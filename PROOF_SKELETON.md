Potential dependency tension:

- `docs/THREE_CONTRIBUTIONS.md` frames C3 as independent, but the main
  C3 design uses an LREE teacher. C3 can be made independent only if the
  student/teacher distillation recipe is explicitly parameterized over any
  contract-preserving teacher, with LREE used as the primary instantiation.
- C3's paper-ready claim depends on implementation and 5-seed results that
  are not yet present. Current `Idea-2C` evidence supports adapter speed and
  strong teacher capture, but not the OPD-Flash delta over off-policy KD.

No formal cyclic proof dependency was found, but there is a narrative cycle:
C2 is defended as independent, while one fallback says C2 can become a
prerequisite for C3's multi-head supervision.

## 4. Canonical Quantified Statements

### C3 On-policy Claim

Current implied statement:

```text
For all graph anomaly cells c and epochs e, OPD-Flash is on-policy because
it computes pi_S^e on all train nodes, forms an entropy/mismatch mask from
pi_S^e and pi_T, and applies reverse KL on that mask.
```

Required stronger statement:

```text
For each epoch e, the training distribution D_e over supervised nodes or
node-label actions is generated by the current student policy pi_S^e, and
the teacher target is queried/evaluated on samples from D_e. The objective is
an unbiased or explicitly biased estimator of a policy-dependent risk.
```

Current status: not established.

### C3 Capture-Rate Bound

Current implied statement:

```text
For bounded teacher logits, bounded student residual, and mask size at least
mu*N, AUPRC(pi_S^phi)/AUPRC(pi_T) >= 1 - C/sqrt(mu*E).
```

Required stronger statement would need at least:

```text
Assume a rank margin around all positive-negative score pairs relevant to
AUPRC, a convergence bound for the masked reverse-KL objective over effective
sample size, sufficient mask overlap with rank-relevant nodes, and a lower
bound on teacher AUPRC. Then translate score/posterior error to ranking loss.
```

Current status: not established.

## 7. Counterexample Candidates

1. AUPRC discontinuity candidate: two nodes, one positive and one negative,
   with teacher scores separated by epsilon. A student perturbation smaller
   than any fixed L2/KL-looking tolerance can reverse the ranking and cause a
   large AUPRC drop. A rank-margin assumption is required.
2. OPD-definition candidate: if the train graph node set is fixed and every
   epoch evaluates all nodes, the data distribution does not change with the
   student policy. Entropy masking is adaptive reweighting, not trajectory
   sampling.
3. Reliability-gating candidate: a low-AUPRC teacher can still be locally
   reliable on exactly the masked hard nodes, while a high-AUPRC teacher can be
   unreliable on hard nodes. A cell-level scalar can down-weight useful
   supervision or up-weight wrong supervision.
